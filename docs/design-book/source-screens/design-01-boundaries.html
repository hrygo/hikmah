设计 01 · 系统边界与代码所有权

产品是独立仓库；AgentScope 与 QwenPaw 是可升级、可替换的上游运行时，不成为产品仓库中的隐式分支。

独立产品仓库（工作名称：协作平台）唯一产品代码所有者
Community Web / API团队空间、频道、线程、成员和实时交互

产品仓库拥有

社交领域数据、成员权限、频道规则、审批记录、Agent 注册映射与审计日志。

AgentScope 拥有

协调 Agent 的会话、运行状态、Team/Pipeline/MessageBus 语义；产品不依赖其内部表结构。

QwenPaw 拥有

Agent 工作区、Skills/Plugins、专业记忆和本地资源；个人 Agent 数据不上传到团队端。
