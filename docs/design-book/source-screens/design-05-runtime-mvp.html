成员设备

个人 QwenPaw成员自行运行、升级与配置；长期记忆和私有技能默认留在本机。
AgentLink Client只需主动连接服务器，不开放本机入站端口；断线后显示离线而非静默代答。
Owner-only 私密会话结果只返回所有者；分享到频道必须由所有者执行明确发布动作。
上游代码边界：产品只依赖 AgentScope 与 QwenPaw 的公开接口并通过自有 Adapter 隔离版本差异。缺失能力先在产品侧适配；确需修改时，仅提交可复用的最小上游 PR，产品等待正式发布并固定版本，不维护私有 fork。

失效与降级

  • 显式 @ 的专家离线：明确告知，不擅自换专家。
  • 协调边车故障：显式 @ 仍直达；未 @ 时请人类选择。
  • 消息以幂等键去重；仅幂等只读操作可有限重试。
  • 副作用执行不盲目重试；状态不明时进入人工核验。
  • Policy、身份或审计不可用时，写操作 fail closed。

验证体系

  • 单元：ACL、策略、TaskRun 状态机、审批失效规则。
  • 契约：对固定版本 AgentScope / QwenPaw 做 Adapter 测试。
  • 集成：@直达、无 @ 路由、专家邀请、审批与知识晋升。
  • 隐私：跨频道泄漏、个人 Agent 越权、能力令牌重放。
  • 端到端：离线重连、部分失败、取消和审计回放。

MVP 成功闭环

  • 3–20 人邀请制 Team Space、频道与线程。
  • 共享专家席位 + 所有者专属本地个人 Agent。
  • 显式 @ 直达与未 @ 的轻量单主答路由。
  • 只读自动执行、副作用审批卡与完整审计。
  • 人审知识晋升；可完成一条真实团队任务。
MVP 内私有小团队协作、文本消息、附件引用、专家协作、基础知识库、管理与审计。
MVP 外公开社区、专家市场、跨组织联邦、计费、移动原生客户端、复杂无代码工作流、聊天自动沉淀全局记忆。
