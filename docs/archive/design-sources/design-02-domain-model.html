首版只有一个私密团队空间；频道承载长期主题，线程承载具体讨论或任务。三类 Agent 身份彼此隔离。

个人 Agent 不是共享成员

不能被其他成员 @，不能直接读取或发布频道消息；主人只能转交选定上下文，并人工确认是否分享结果。

协调边车不是专业专家

不回答领域问题，不拥有业务工具权限；其输出仅限路由、秩序、审批、总结和知识治理。

权限按能力而非“Agent”整体授予

读取频道、回复、检索知识、调用工具、执行副作用分别授权；拒绝默认拥有主人的全部权限。
