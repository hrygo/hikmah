# 交互画布源材料

本目录保存 Hikmah 架构讨论过程中生成的原始 HTML 片段，用于追溯设计演进。

这些文件原本由 brainstorming visual companion 注入统一页面框架，因此单独打开时不保证具有完整样式或交互能力。可独立阅读和打印的版本是上级目录中的 hikmah-design-book.html。

原始画布中的工作名称、候选方案和交互按钮属于历史记录。正式命名和最终决策以以下文件为准：

- [产品与技术架构](../../product/overview.md)
- [HTML 设计册](../../design/hikmah-design-book.html)
- [设计批准与修订记录](../../design/approval-record.md)

`manifest.sha256` 记录 7 个源 HTML 片段当前归档版本的 SHA-256，用于验证内容未被意外改写。2026-08-28 文档重组只为片段增加了不参与渲染的 metadata 注释，并同步刷新了 manifest；画布样式与正文保持不变。
