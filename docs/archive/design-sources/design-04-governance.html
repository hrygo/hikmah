设计 04 · 记忆、隐私与执行治理

记忆按作用域隔离，知识只能经人审晋升；动作按能力授权，审批绑定到精确执行计划。

记忆边界 · 默认不跨频道

线程 / 频道记忆普通对话、阶段结论和附件引用留在原频道；专家只收到当前任务所需的最小上下文。
专家稳定记忆专家身份、专业能力、技能版本与安全约束可全团队复用，但由管理员管理，不从聊天中自行改写。
团队知识库仅收录已审阅的知识对象；每条保留来源、作者、适用范围、敏感级别、版本和失效状态。
个人 Agent 记忆仅所有者可用，本地 QwenPaw 的长期记忆默认留在本机；平台不把它注入团队专家，也不让管理员浏览正文。
唯一跨频道路径
知识候选→人类审阅→定范围 / 脱敏→发布团队知识→版本化 / 撤回
硬规则：模型不得把聊天内容自动升级为全局记忆；“总结”不等于“发布”。没有明确的人类确认，内容就留在原作用域。

执行治理 · Policy 独立于协调边车

自动执行
只读检索、分析、草稿和无外部副作用的计算；仍记录工具、输入范围与结果摘要。
审批或规则放行
写文件、发消息、变更任务、调用业务系统等副作用；管理员可预先放行边界清晰的低风险动作。
拒绝执行
超出 Agent、成员、频道或工具能力范围；目标不明确、参数漂移、凭据缺失或策略冲突时默认拒绝。
Execution Card · 人类看到的审批契约
谁提出主答专家 + 发起成员
准备做什么工具、目标与精确参数
影响范围对象数量、外部收件方、可回退性
执行预览diff / 消息预览 / 变更摘要
审批不可泛化：批准只绑定当前计划、参数、作用域和有效期；任何实质变化都使审批失效并重新请求。边车和专家均不能代替人类批准。
个人 Agent 是“隐私隔离区”，不是频道成员
所有者选择上下文→最小化 Context Envelope→个人 / 本地 QwenPaw 私下处理→结果仅所有者可见→所有者主动“分享到频道”
统一审计事件流（正文按权限可见，绝不记录密钥或模型私有推理）
